# TRIM11 Upregulator Analysis in Alzheimer's Disease

This repository contains code used for identifying candidate upstream regulators of TRIM11 using single-cell and single-nucleus RNA sequencing datasets.

## Overview
- RLE normalization of sc/snRNA-seq data
- Pearson correlation analysis
- Bayesian network inference (hill-climbing, BIC)
